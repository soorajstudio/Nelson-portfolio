## ✦ Overview

This portfolio celebrates the meteoric career and filmography of **Naslen K. Gafoor** (Kodungallur, Thrissur, Kerala). Engineered with a high-performance monochrome editorial aesthetic, WebGL liquid lens shaders, and a horizontal spatial timeline, it showcases his journey from an overnight sensation to headlining one of the highest-grossing Malayalam movies of all time (*Premalu*, ₹136+ Crore worldwide).

---

## ✦ Key Sections

### 1. 🎭 Editorial Hero
- Large metallic gradient typography: **`NASLEN K. GAFOOR`**.
- Actor credentials (`EST. 2000`, `Kodungallur • Kerala`), signature youth disciplines (`ROM-COM & DRAMA`, `COMING-OF-AGE`, `FEATURE FILMS`).
- Social channels linked directly to his official IMDb and Instagram.

### 2. 🧭 Horizontal Journey Timeline ("Where I've Been")
- **2019 — 2022 (Breakthrough & Critical Acclaim)**:
  - Viral breakout debut as Melvin in *Thanneer Mathan Dinangal* (2019).
  - Won the **SIIMA Award for Best Comedian** for *#Home* (2021) as Charles Oliver Twist.
  - Intense dramatic performance as Rasool in *Kuruthi* (2021).
- **2024 — Present (Pan-Indian Blockbuster Stardom)**:
  - Career-defining lead role as Sachin Santhosh in Girish A.D.'s **`Premalu`** (2024), crossing **₹136+ Crore** at the global box office.
  - Pan-Indian youth stardom across Kerala, Tamil Nadu, Andhra Pradesh, and Telangana.
  - Upcoming marquee slate including *Alappuzha Gymkhana* (dir. Khalid Rahman) and *Lokah Chapter 1: Chandra*.

### 3. 🌊 Featured Films (OGL WebGL Liquid Carousel)
- Interactive card slider powered by **OGL** (lightweight WebGL engine) with liquid lens physics:
  - **Premalu** (2024) — *All-Time Blockbuster Romantic Comedy*
  - **Lokah** — *Chapter 1: Chandra*
  - **Home & Thanneer Mathan Dinangal** — *Critically Acclaimed Cult Hits*
- Dynamic project modal with box office statistics, character insights, and production details.

### 4. 📩 Enquiries & Casting Modal
- Form for feature film roles, brand ambassadorships, youth commercial endorsements, and celebrity appearances.

## ✦ Running Locally

```bash
# Clone or open directory
cd Neslon-portfolio-main

# Start server using Python
python -m http.server 8080

# Or with npm
npm start
```

Visit `http://localhost:8080` in your web browser.
